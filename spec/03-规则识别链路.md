## 0. 定位：纯离线、确定性规则解析器

`RuleBasedBankGenerator::generate(const QList<ExtractedDocument>&, bool hasAnswerKey = true)`（`:2191`）。

- **无状态、无网络、无窗口**；相同输入必须相同输出（`rule_based_generator.hpp:12-19`）。
- 算法只用"题号、选项、答案、解析、材料范围"等可解释规则。
- 输出 `RuleBasedGenerationResult`（即 `ReviewResult` 的 using 别名，`rule_based_generator.hpp:15`）。
- **没有"规则失败 → 调模型"的 fallback**：MinerU 只是上游提取后端，不是降级目标
  （`generation_workflow.cpp:18-147` 里规则失败只是 `Failed` 阶段 + `emit failed`，
  无任何模型客户端调用）。

## 1. 套题 vs 单套题：splitBookletSections（`:946-1055`）

在 `generate()` 最前端对每份文档调用（`:2197`），切分后**每套独立跑完整管线**
（答案区扫描、材料归属、重号判断都在套内进行），所以"实战演练一 1.A"与"实战演练二 1.B"互不冲突。

### 1.1 两类标题正则

**强标题**（`:948-949`）：
```
专项刷题[一二三四五六七八九十百\d]+
| 第[一二三四五六七八九十百\d]+套(试题|试卷|练习题)?
| (试卷|套题)[一二三四五六七八九十百\d]+
```

**裸章节标题**（`:954-955`）：
- `(实战|模拟|专项|强化|基础|巩固|综合|同步|真题|单元)(演练|练习|训练|测试|刷题)(数字1-3位)`（如"实战演练一"）
- `[一二三...]{1,3}(部分|章|节|卷|篇|组|单元)(可选 1-12 字题型名)`（如"第一部分 片段阅读"）
- 或 `第[数字]部分/章/...`

### 1.2 切分必须同时满足的启发式条件（宁缺毋滥）

注释 `:942-945`："误切会把题目切碎，比不切更有害"：

1. **标题独占整行**：`isFullLine`（`:994-997`）要求 `captured(0) == text`，
   题干里出现"本题来自实战演练一"不会被当边界（回归 `rule_based_generator_test.cpp:1336-1351`）。
2. **标题行长度 ≤ 24**（`:1000-1001`）。
3. **题号重启校验**（`:1008-1020`）：标题后到下一个标题前，**第一道题必须是第 1 题**。
   目录行、题干短行、不重启编号的分节标题都在此被挡掉。
4. **目录页排除**（仅裸标题，`:1021-1022`）：`tocPageBefore`（`:984-989`）
   检查标题所在页（按 `\f` 分段）之前是否出现过"目录"二字。
5. **答案对行不算题号**：`answerPairLine`（`:958-959`）把整行"1.A 2.B"排除出"第一道题"判定。

### 1.3 切分产物

- 每套一个 `ExtractedDocument` 副本：`sectionId="set-N"`、`sectionTitle=标题行`、
  `firstPageNumber += 标题前的 \f 数量`（`:1042-1053`，保持**原始绝对页码**）。
- 第一个标题之前的未命名试题（含题号行+选项行，`:1027-1041`）不丢弃，
  作为 `sectionId="set-prefix"`、`sectionTitle="未分套题目"` 的独立套。
- 无边界时返回原文档单套（`:1025`）。

下游效果：套级隔离（答案/材料/漏题检查按套进行）；`source` 携带
`sectionId/sectionTitle`（`:1971-1974`）。

独立答案册保存在 `ExtractedDocument::companionAnswerText`，不会在 workflow 中提前拼进
题目正文。`generate()` 先切分题本；答案册含与题本完全一致的套题标题时，
`companionAnswerTextForSection()` 只把对应标题段追加到该套。标题无法匹配时，各套看到
同一份答案文本并继续受题号、数量与冲突规则约束；重号冲突不会被猜测绑定。

⚠️ 区分两层标题：`isTopLevelSectionHeading`（`:229-233`，`^[一二三]+、\s*\S`）是
**大题标题**（单选/多选/判断分区），用于多答案信号传播，**不做文档切分**。

## 2. 答案解析：四种位置**全部支持**，各有独立代码路径

### 2.1 位置①：题目内嵌答案（题干括号 / 行内 / 行尾）

| 形态 | 规则 | 位置 |
|---|---|---|
| 整行 `答案：A` / `【答案】A` / `正确答案：A` | `inlineAnswerPattern` | `:180-184`，消费 `:1740-1745` |
| 行尾显式 `… 答案：A` | `trailingExplicitAnswerPattern`，只剥行尾字母 | `:1612-1616`，题干首行 `:1712-1716`、选项行 `:1761-1765` |
| 题干括号 `（ A ）` / `(A)` / `【A】` 等 | `bracketAnswerCandidates` | `:1524-1537`，处理 `:1781-1812` |

**括号答案的采用条件**（`:1781-1812`）：唯一括号候选 + 选项完整（≥2、标签唯一）+
括号内字母全部是合法选项 → 采用，并把括号内替换为全角空格 `blankBracketAnswer`
（`:1619-1640`，同步重映射下划线 UTF-16 坐标）。
**冲突时保留原文 + hard 复核**（4 种理由文案 `:1784/1796/1798/1806`）：
多处疑似括号、选项不完整、多字母但未标多选、与显式答案/答案表冲突。
（`docs/embedded-answer-recognition.md` 与此一一对应。）

### 2.2 位置②：每道题后答案

`parseQuestion` 的逐行状态机（`:1736-1779`）在选项出现之后继续消费
`inlineAnswerPattern` / `trailingExplicitAnswerPattern` 命中行——
"题目 + 选项 + 答案：X"的题内布局天然覆盖。
注意：**单题的"答案：A"不是答案区头**（措辞门槛见 2.3，测试 `:1233-1241`）。

### 2.3 位置③：整套题后答案（卷末答案区）

**答案区头识别**：
- `isAnswerSectionHeader`（`:192-198`）：整行 `答案/参考答案/答案对照表/答案汇总/答案及解析/参考答案及解析`（可带【】与冒号）。
- `isInlineAnswerSectionHeader`（`:208-215`）：标题与答案串同行，如"【参考答案】CAACD DBABC"。
  **措辞区分单题/整卷**：`参考答案/答案汇总` 两个字母起即判答案区；
  裸"答案"要求 ≥6 个字母（避免把单题"答案：A"误当答案区起点，注释 `:200-207`）。

**答案区内容解析 `globalAnswers`（`:1299-1443`）支持五种子形态**：

1. **表格化**（`:1319-1366`）：`题号 | 1 | 2 | 3` / `答案 | A | B | C`
   （含 markdown `|` 与全角 `｜`），按列对齐配对；
2. **按题号对**（`pairPattern` `:1371-1375`）：`1.A 2.B`、`第 1 题 答案 A`，一行可多组；
   "…项/选项"结尾的（如"1. A 项正确"）被排除（`:1417-1419`）；
3. **区间答案**（`range` 正则 `:1376-1377`，展开 `:1393-1410`）：`1~5: DDCBC`、`1-5 至/到`，
   **一行可含多组**（"只取第一组会丢掉后半卷的答案"），展开后长度必须与题号数严格相等；
4. **判断题**（`booleanRecord` `:1425-1433`）：`1.√ 2.×`、`1.对 2.错误`，
   经 `booleanAnswerLabel`（`:839-857`）归一化到合成选项 A(正确)/B(不正确)；
5. **叙述式**（`narrativeAnswer` `:1434-1440`）：解析末尾"故正确答案为 C"，
   归属最近一个题号（`currentNumber` `:1378-1379`）。

**作用域** `answerSectionEnd`（`:1273-1289`）：到下一个题号锚点或下一个材料头为止——
保证"阶段一题+阶段一答案+阶段二题+阶段二答案"文件中阶段二不被阶段一答案区吞掉。
多个答案区段逐个扫描（`:2439-2456`），跨段冲突进 `ambiguousAnswerNumbers`。

### 2.4 位置④：整个文件最后答案（无题号连续字母串）

`contiguousAnswerRun`（`:1449-1468`）：整段只有字母（A-F/圈码）无任何题号；
出现数字、标点、汉字即整段放弃。采用策略（`:2554-2624`）两档安全约束：

1. **整卷数量精确相等**（`run.size() == anchors.size()`，`:2575`）→ 按顺序一一配对；
2. **部分覆盖**（`:2588-2614`）：答案串严格对应**唯一一段**连续递增且两端断开的题号区间
   ——覆盖"真题答案串只覆盖主体大题，卷末附带无答案练习"的场景。

不满足时题目进复核，**绝不错位写入**（`:2547-2553`："不能用 answers.isEmpty() 当守卫"）。

### 2.5 其他位置与兜底

- **题干之前的集中答案**（粉笔网页导出："正确答案：C"排在题目前且无题号）：
  仅当数量 == 题数时按顺序配对（`:2534-2545`）；数量不足 → 全部复核。
- **章节题号重启的位置兜底**（`:2462-2529`）：章节标题形态未知导致题号逐章重启时，
  答案表按"紧邻题块 + 连续区间 + 存在重号"按**位置**绑定，重号题打
  `duplicate-number-positional-answer` soft 信号；
  "整卷一张表 + 前面两段同形题块"无法归属时**整段拒绝**（`:2509-2521`）。
- **解析**：题内 `solutionPattern`（`:186-190`，`【解析】/解析/解答/说明`，消费 `:1746-1757`）；
  卷末 `globalSolutions`（`:1470-1520`，"1.A 解析：…"记录式）。
- **重号题答案隔离**：题号重复时按题号绑定的答案/解析**不传播**（`:2681-2686`），
  题内答案仍可用。

### 2.6 答案 → 选项映射

- `normalizeAnswer`（`:806-834`）：字母/圈码/括号数字统一为大写字母串。
- `answerFromOptionText`（`:874-893`）：先按字母直接映射；失败时按**去标点空白后的文本**
  与选项正文匹配，长度 ≥4 且双向包含即候选，**多候选则拒绝**——
  所以"标准答案：蓝色"能映射到选项"蓝色"。

### 2.7 是否含答案的自动检测

资料行默认 `AnswerPolicyHint::Auto`。`GenerationWorkflow` 先用 `hasAnswerKey=true` 完整运行
规则引擎，再统计“成功绑定到具体题目的非空答案数 / 全部题数”：

- 覆盖率 **≤5%**：用 `hasAnswerKey=false` 确定性重跑，少量误识别、孤立答案记录或无法
  对齐的答案串不能把整库锁成含答案语义；
- 覆盖率 **>5%**：保留含答案结果；无法对齐的题仍 hard 复核；
- 配对独立答案册：直接视为含答案；
- 用户仍可用 `Included/None` 强制覆盖，冲突的显式覆盖继续拒绝混合。

`ReviewResult::answerEvidenceDetected` 只保留作诊断，不再一票决定题库策略。覆盖率只计入已经
映射到合法选项的逐题答案，不计标题、孤立记录和未对齐答案串。最终 bank.json 仍只有
`answerPolicy=included|none` 两态；人工 Included 与配对答案文件不受 5% 阈值覆盖。

## 3. 切题（题目分割）算法

### 3.1 管线顺序（`generate()`）

1. `stripRepeatedPageFurniture`：对外部构造的 `ExtractedDocument` 幂等清理重复页眉页脚；
   正式本地 PDF / MinerU 提取阶段已经执行，完整规则见 [02](02-文档提取与扫描件处理.md) §2.6
2. `splitBookletSections`（套题切分，见 §1）
3. `sourceLines`：NFC 归一化；`\f`→页边界；CRLF 合并；
   空行置 `paragraphBreakBefore`；页脚过滤 `^[-—–\s]*\d{1,4}[-—–\s]*$`（"- 15 -"，`:923-924`）
4. `normalizeTrailingQuestionNumberLayout`（`:58-95`）：网页导出 PDF 把题号画在题干**之后**
   （"题干…\n1.\nA.…"）时，题号行无题干文字则把紧邻前置题干**折回**题号行；
   硬边界：空行、`正确答案：`/`你的答案：`、选项行、上一题号行——绝不跨题拼接
5. `recoverSingleMissingQuestionNumbers`（`:101-178`）：原卷漏印单个题号的受限恢复，
   须同时满足：上一题已有 D 选项、候选行 ≥12 字且不是题号/选项/答案区/章节行、
   候选块在下一题前拥有完整 A-D、PDF 坐标上候选与 D 选项有明显段距
   （`top - bottom > max(0.004, 0.35×行高)`，**需要 lineAnchors**）。
   恢复出的题打 `inferredNumber`，强制软复核（signal `question-number-inferred`）
6. 锚点扫描 → 逐块 `parseQuestion`（`:1665-2063`）

### 3.2 题号正则 `questionPattern`（`:47-56`）

```
^\s*(?:(?:问题|题目)\s*)?(?:第\s*)?(\d{1,4})\s*
(?:题 | [．、:：\)）] | \.(?=\d{4}\s*[年\-~～—]|\d{1,2}\s*世纪) | \.(?!\d))\s*(.*)$
```

- 支持 `1. 1、 1） 第1题 问题1`；
- `\.(?!\d)` 排除小数"1.5 倍"；**例外**：句点后跟四位数字+年/区间记号
  （"111.2016年～2020年"资料分析题干）按题号处理（测试 `:1121-1163`）；
- 捕获组 2 = 题号后首行题干（`firstStemLine`）。

**锚点扫描排除三类行**（`:2246-2264`）：答案区头行、整行答案对行（`:2243-2244`，如"1.A 2.B"）、
最后一个答案区头之后的所有行（`:2253-2255`，属于末尾答案区解析文本）。

### 3.3 题目块边界 `blockEnd`（`:2655-2664`）

= 下一锚点行，但被两类边界**提前截断**：
- 答案区头（`:2659-2663`）：题目区到答案区为止；
- 材料头 `nextMaterialLine`（`:1658-1663`）：防止下一组材料被追加到上一题最后一个选项。

### 3.4 块内题干/选项切分（`parseQuestion` 逐行状态机 `:1736-1779`）

1. 行命中 `inlineAnswerPattern` → 记答案；
2. 命中 `solutionPattern` → 进入解析收集态；
3. 剥离行尾显式答案；
4. `optionsOnLine`（`:1546-1610`）切选项，marker 正则（`:1552-1558`）覆盖：
   字母+分隔、**字母+空格（无标点，WPS 省略点号场景）**、圈码+可选分隔/空格、`(1)`、`1)`；
   - **单 marker 且前面有文字 → 拒绝切分**（`:1583-1585`，避免把含"B."的英文题干误切）；
   - **≥2 marker → 切分**，marker 前文字作为题干前缀回传（覆盖"1. 题干 A.甲 B.乙 C.丙 D.丁"单行写法）；
   - **单 marker 在行首 → 纯选项行**（正常路径）；
   - 括号内字母不算选项 marker（`bracketAnswerCandidates` 排除 `:1560-1568`："（ A ）"不是选项"A）"）；
   - **数字标签门控**：题内已有显式 A./B. 时 `allowNumericLabels=false`，
     ①②/(1)/(2) 视为题干条件编号而非选项（`:1569-1571`、`:1705-1708`）；
   - Markdown 列表符 `-`/`•` 不作为题干前缀（`:1578-1581`）；
5. 选项出现后的续行 → **合并进最后一个选项**（`:1773-1775`）；此前行 → 题干。

题干行经 `buildMaterialText`（`:1780`）做**视觉行重排**：`reflowVisualLines`（`:1113-1152`）
用 PDF 行坐标判断——垂直间距 > 0.85 行高或首行缩进 > max(0.012, 1.25 字符宽) → 新段落；
PDF 折行直接拼接（仅 ASCII 单词折行补空格）。

### 3.5 材料（长阅读/资料）锚点

- 材料头 `isMaterialHeader`（`:217-221`）：`（一）材料/资料/阅读材料 N`、`阅读下列/以下材料|文字`、
  `根据下列/以下(统计)资料|材料`、`原文：`；
- 材料分隔 `isMaterialSectionMarker`（`:223-227`）：裸`（二）`行，仅当**下一非空行确为材料头**
  才作为起点（`:2270-2278`，避免粘到上一题 D 选项）；
- 材料与题的关联（`:2284-2324`）：
  有"根据材料回答 N-M 题"（`rangePattern` `:2234-2235`）→ 题号区间限定；
  无范围字样（阅读理解）→ 归属截到**下一大题标题前最后一道题**；
  `materialIdForQuestion`（`:1642-1656`）按行号+题号区间双向匹配。

### 3.6 选项标签体系（`option_label.hpp` + `canonicalOptionLabel`）

NFC 归一化后支持：A-I / a-i、全角 Ａ-Ｉ、圈码 ①-⑳（U+2460-2473）、
带点数字 ⒈-⒐（U+2488-2490）、括号数字 `(1)/（1)/[1]/{1)/「1)/『1)` 及尾括号 `1)`。
**NFC 而非 NFKC**——NFKC 会把圈码 ① 分解成裸 1（`:796-802` 注释）。

## 4. 题型识别

运行时合法题型（`core/src/bank_validator.cpp:23`）：
`single_choice / multiple_choice / true_false`。

判定顺序（`parseQuestion` `:1950-1965`）：

1. `forcedTrueFalse`（空括号判断题合成）→ `true_false`；
2. `allowsMultiple && (answerIds.size() > 1 || !hasAnswerKey)` → `multiple_choice`（`:1955-1956`）；
3. 恰好 2 个选项且文本为 正确/错误 或 对/错 → `true_false`（`:1957-1965`）；
4. 否则保持 `single_choice`（默认值 `:1950`）。

**多答案信号来源**（`:1936-1945`）：
- 题干显式：含"多选/多项选"（strict）或"不定项"（`:1941-1943`）；
- **section 大标题传播**：`isMultiAnswerSectionHeading`（`:306-314`，
  匹配"多选|多项选|不定项"且必须整行大题标题 `^[一二三]+、` 或 `（多选题）`括号行）→
  收集 `sectionHeadings`（`:2644-2649`），取**题号行之前最近的一个大标题**传播
  `allowMultipleAnswers`（`:2667-2672`）——"三、判断题"会取消上一段的多答案属性。

**校验**：strict 多选（题干写"多选"且非不定项）**要求答案 ≥2**（`:1948-1949`，
未满足 → 复核且 type 仍 single_choice）；section 传播/不定项允许单答案
（不定项单答案判 `single_choice`，测试 `:932-966`）。

**判断题两条识别路径**：
1. **空括号判断题**（`:1829-1845`）：无选项且题干以 `（ ）`/`( )` 结尾
   （`hasBlankJudgmentBrackets` `:861-865`）→ **合成** a=正确、b=不正确 两个选项，
   答案由 `booleanAnswerLabel`（`:839-857`）从 对/错/正确/错误/√/×/是/否 归一化
   （**先判否定**；刻意不收 T/F/Y/N 单字母避免残片答案误判，`:836-838`）；
2. 选项文本判定：两个选项文本含 正确/错误 或 对/错（`:1957-1965`）。

**填空题**：没有独立 `fill_blank` 题型——用 `〔填空〕` 占位符 + `stemUnderlines`/`underlines`
区间表达（见 [02](02-文档提取与扫描件处理.md) §4），题目本身按选项结构归类（通常单选）。

**简答/主观题：不支持**。没有选项的题因"未识别到至少两个完整选项"（`:1927-1928`）进 needsReview。

## 5. 输出结构

### 5.1 题目 JSON（`parseQuestion` 构造 `:1975-2062`）

```jsonc
{
  "id": "r<文档序>-q<原始题号>-<全局递增序号>",   // :2673-2676；originalQuestionNumber 从 id 回解 :2067-2071
  "catalogId": "generated",
  "type": "single_choice | multiple_choice | true_false",
  "stem": "多行题干（\n 连接，含〔填空〕占位）",
  "stemUnderlines": [{"start":n,"length":m}],     // 仅当题干与装饰文本一致 :1981-1982
  "options": [{"id":"a","text":"...","image":{...}}],  // image 仅 MinerU 可信坐标时
  "answer": {"optionIds":["a"]},                  // hasAnswerKey 时 :1983-1984
  "solution": "解析文本",
  "materialId": "r<doc>-m<n>",
  "stemImage": { "path","alt","sourceDocument","sourcePage",
                 "autoCrop":{x,y,width,height} },  // 归一化 0..1 :2000-2012
  "source": { "document","page",                 // page 仅 lines[].page>0（PDF 有页边界）
              "questionNumber": N 或 "1-1",              // 原题号可为正整数或非空字符串
              "questionLabel": "N" 或 "原第 N 题 · 同号第 X 处",  // 重号 :2726-2727
              "sectionId","sectionTitle" },
  "review": { "needsReview": bool,
              "confidence": 0.25(hard) / 0.6~0.7(soft) / 0.75~0.95(ok),
              "reason","riskLevel":"hard|soft",
              "signals":["image-content","ocr-source","material-type:图形推理",...] }
}
```

附件描述符统一由 `visualAssetDescriptor`（`:326-342`）生成；
来源仅记录文件名、页码和归一化坐标，**不含本机绝对路径**（`:329-333`）。

### 5.2 材料 JSON（`:2382-2426`）

`{id:"r<doc>-m<n>", catalogId:"generated", title(≤200字), body,
source{document,page}, underlines?, images?, review?}`。
资料分析材料强制 soft 复核（`:2419-2425`，signal `material-type:资料分析`）；
未引用材料在末尾剔除（`:2772-2784`）。

## 6. 三级复核分流（hard / soft / ok）

`parseQuestion` 尾部 `:2041-2061`：

| 级别 | 去向 | confidence | 触发 |
|---|---|---|---|
| **hard** | `needsReviewQuestions`（UI 默认不勾选） | 0.25 | 括号答案歧义（4 种文案 `:1784-1806`）；同页原题号重复无法定位题图（`:1918-1922`）；重复选项标签（`:1923-1924`）；缺题干（`:1925-1926`）；<2 个完整选项（`:1927-1928`）；未识别到答案/答案无法唯一匹配/引用不存在选项（`:1929-1934`，仅 hasAnswerKey）；未标多选却多答案（`:1946-1947`）；多选答案少于两个（`:1948-1949`）；重号且答案无法解析（`:2731-2739`）；答案表同题号冲突（`:2748-2757`） |
| **soft** | 留在 `questions`（自动收录、默认勾选） | 0.6(OCR)/0.7 | `material-type:图形推理`（`:2023-2024`，`isInsideGraphicalReasoningPart` `:288-299`——规则原理上无法验证图形规律）；`stem/material-layout:underline-or-blank`（`:2028-2033`）；`image-content`（`:2037-2038`）；`ocr-source`（`:2039-2040`）；批量审计信号（见下） |
| **ok** | `questions` | 0.95(纯文字)/0.75(OCR) | — |

`withReviewSignal`（`:2076-2094`）保证批量信号**只能加严**：已有 hard 不会被降为 soft。

### 批量统计审计 `applyRuleBasedGenerationAudit`（`:2100-2187`）

按"文档+section"分组，样本 <4 不做统计（`:2111-2112`）：
1. **题号连续性**：覆盖区间有缺口 → 整批 warning（含 needsReview 的题号补回统计）；
2. **选项数众数**：众数占比 ≥75% 时偏离者打 `option-count-outlier` soft（`:2140-2159`）；
3. **答案分布偏斜**：仅 ≥8 题启用，单一答案占比 ≥60% 时该字母所有题打 `answer-distribution-skew`（`:2163-2184`）。

## 7. 视觉回退链（图/表题）

`options.size() < 2` 且题干含 图/表/统计/问号（`:1852-1854`）或有"如图所示"等显式指图表述
（`:1858-1860`）时：

1. 选项清空，合成 `a-d = 图A..图D`（`:1865-1875`）；
2. MinerU 可信坐标 → **四张独立选项图**（`:1879-1887`，仅 `extractionBackend.startsWith("mineru")` 且四标签同行完整）；
3. 否则整题裁图 `extractQuestionVisualImage`（`:656-794`）：
   下边界 = 下一题题号（`nextQuestionBoundsFor` `:642-654`），**绝不回退整页**
   （唯一例外：测试夹具/损坏 PDF 缺题号锚点 `:2005-2012`）；支持跨页拼接（`:752-783`）；
4. 仍无图且命中重复选项/版式线索 → `captureSourceBlock` 原卷题目截图（`:2014-2018`，最多 4 页，`:495`）。

材料图：`extractMaterialLayoutImages`（`:396-484`，含 chartOnly 长直线检测 `:430-471`）。

## 8. 文档级失败与降级

- 提取失败 → `ExtractedDocument.error`，workflow 直接 `Failed`（`generation_workflow.cpp:85-88`）；
- OCR 未启用/失败 → 逐页 warning + 汇总（`document_extractor.cpp:605-616`）；
- 整份无锚点 `anchors.isEmpty()`（`:2626-2638`）：区分三种 warning
  ——OCR 未启用（"这不是题号格式问题"）、OCR 失败（透传首条 warning）、普通"没有识别到题号锚点"；
- 整个批次 questions 与 needsReviewQuestions 都为空 → workflow Failed（`generation_workflow.cpp:131-137`）。

## 9. 已知坑与边界条件（写代码前对照）

### 9.1 正则/文本层

| 坑 | 处理 | 位置 |
|---|---|---|
| 小数"1.5倍" vs 题号 | `\.(?!\d)` 排除 + "111.2016年"例外 | `:48-56` |
| 圈码 NFKC 分解 | 全程用 NFC | `:796-802` |
| CRLF 污染段落判断 | sourceLines 合并 | `:902-909` |
| MinerU 空白规范化/幻读 | 去空白 key + 8 连续字符 ≥60% 模糊匹配 | `document_extractor.cpp:647-657` |
| 页脚"- 15 -" | sourceLines 剔除 | `:923-924` |
| 页眉页脚重复家具 | `stripRepeatedPageFurniture`：边缘 bbox + 40% 跨页阈值；无坐标首尾行用 65% 阈值 | `document_extractor.cpp` / [02](02-文档提取与扫描件处理.md) §2.6 |

### 9.2 重号（同号）题——最大的已知坑簇

`tests/duplicate_question_number_test.cpp` 全文覆盖：
- 同号题独立 id + `"原第 N 题 · 同号第 X 处"` label（`:2724-2728`），判分互不覆盖；
- **按题号的答案表/解析绝不复制给多道同号题**（`:2681-2686`）；
- 题内括号答案（`1.甲（A）`）仍可用（`:1808-1810`）；
- 位置绑定要求"连续区间+存在重号+锚点前序匹配"，整卷单张表+两段同形题块 → **全拒绝**（`:2509-2521`）；
- 同页重复题号坐标 → 题图裁切直接放弃并 hard（`questionBoundsFor` `:344-352`）。

### 9.3 答案位置

- 单题"答案：A"**不是**答案区头（措辞门槛 `:200-215`）；
- 卷末"补充练习"位于最后一个答案区之后 → 被当解析文本剔除、不生成题
  （测试 `:1181-1214` 注释承认这一行为）；
- 连续答案串两段同形 → 全部放弃（测试 `:1217-1229`）；
- 答案表同题号两个不同答案 → 该题号答案+解析整体移除、hard 复核；
- 倒序题号 `2. 1.` 配"答案 1.A 2.B" 仍按题号正确绑定。

### 9.4 视觉/版式（均有回归测试）

- **北京卷第 76 题**：文字层 A/B/C/D 坐标不可靠时把第 77 题文字裁进选项 → 统一整题裁切
  （`:533-535`、`:1865-1869`）；分数/公式选项向上留 9% 页高（`:696-700`）；
- **"如图所示"插图题**：不能用公式选项的窄条裁切，否则截掉示意图顶部（`:710-720`）；
- 题干尾裸标签行"A、 B、 C、 D、"从 stem 移除（`bareVisualLabels` `:1890-1895`）；
- 材料跨页（正文在上页、图表在下页）只截图表页（chartOnly 检测 `:430-471`）；
- 裁切安全上界：材料图终点必须是"完整题干行"锚点，题号锚点失效时**宁可无图**（`:413-421`）；
- 下划线/填空只对有"划线/横线"线索的题按需检测（`:2330-2344`）。

### 9.5 运行语义

- `hasAnswerKey=false`：不校验答案、不写 answer/solution、多选判定放宽（`:1955`）；
  可确认的括号答案仍清理但不写 answer；
- 默认由程序自动确定整批含答案/无答案；多份资料的显式 `Included/None` 覆盖互相冲突时拒绝；
- 真实样本回归：147 页国考刷题题本 → 20 套、598 道可用、1 个硬复核块
  （第 61 页漏印第 11 题，`docs/booklet-recognition-regression.md:33`）；
  30 页《08257 舆论学》→ 188 题通过、188 份括号答案提取（`docs/embedded-answer-recognition.md:29-31`）。
