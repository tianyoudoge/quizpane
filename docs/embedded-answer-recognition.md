# 题干括号答案识别

选择题的答案可直接写在题干开头、中间、结尾或跨行括号中，例如
`（ A ）是指……`、`周公旦（A），……`、`……（B）。`。
规则在完整题干与选项分离后匹配，不依赖联网或 AI。

- 成对括号内只允许选项字母和常见分隔符；支持大小写、全角字母及多选答案。
- 选项必须完整、标签唯一，且答案引用的选项存在。
- 题干出现多处疑似括号答案、与显式答案/答案表冲突，或多字母但未标注多选时，保留原文并转人工复核。
- 成功时只将括号内的答案替换为一个全角空格，保留括号及位置；`吉礼（祭礼）` 等注释不变。
- 选项、解析中的括号不参与题干答案匹配。清理后同步映射题干下划线的 UTF-16 坐标。
- “无答案题库”模式也清理可确认的括号答案，但不写出 answer 字段。
- 空题号不向前吞并上一题的分行选项。同一分套内重号保留原号码，全部转人工复核；跨分套重号仍允许。

## 回归

`embedded_answer_test` 覆盖上述边界，以及题干与选项同行、正常括号注释、下划线与 emoji 偏移。

真实 PDF 不入库。含内嵌答案的题库可本地运行：

```sh
build/release-macos/tests/pdf_regression_harness --embedded-answers /path/to/questions.pdf /path/to/output
```

用户提供的 30 页《08257 舆论学》样本：186 题通过结构校验，9 个候选需人工处理；
共 188 份括号答案可提取（含原卷两道同为 152 的题，因重号保留复核）。
未自动采纳的其余情况为：139 是空题号；180–185 的选项无常规分隔符，尚未安全拆出完整选项。
不猜测答案、不静默改号，也不把这些异常计作成功题目。
