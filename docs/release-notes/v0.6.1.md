# 小窗刷题 v0.6.1

本版本为 v0.6.0 的补丁版本，专项改善 Windows 7 x86 兼容性，并强制所有 Win7 包内置离线 OCR。

## Windows 7 x86 兼容性

- 修复 Win7 x86 运行时兼容问题，改善低内存设备上的预览内存上限控制。
- Win7 包（x64/x86）默认启用本地 OCR，不再依赖网络服务；release.yml 同步更新以确保发布包携带 OCR 运行库。
- 所有 Win7 构建均强制包含离线 OCR，CI 与正式 Release 行为一致；新增 `windows7-required-features.cmake` 和对应的 CMake 测试确保构建约束可验证。
