# 小窗刷题 v0.5.5

本次补丁加入 Windows 7 离线 OCR 的实验性构建能力，并修复扫描题本识别链路中的兼容与错误处理问题。

## Windows 7 OCR

- 新增 Win7 x86/x64 离线 OCR 构建开关，固定使用 MSVC v142、Tesseract 5.5.2、Leptonica 1.85.0 和中英文模型。
- OCR 依赖与模型随绿色包携带，识别过程不需要联网、Python 或额外安装运行库。
- 修复中文模型路径、损坏模型报错、可读封面掩盖扫描正文等问题。
- 新增中文解压路径、真实扫描 PDF、损坏模型、程序架构及 Win8+ API 导入检查；x86/x64 自动化验证均已通过。

## 平台说明

- Win7 OCR 当前仍为实验能力，可通过 `scripts/build-windows7.ps1 -EnableOcr` 构建；正式 Release 的 Win7 包暂不默认启用 OCR。
- 自动化验证运行在 Windows Server 2022；在 Win7 SP1 x86/x64 实机验收完成前，不提升兼容性承诺。
- Windows 10/11、macOS、Linux 及浏览器扩展的发布方式保持不变。
