# 小窗刷题 v0.4.2

本次修复网课伴侣在多 iframe 直播回放页面中的播放器聚焦与交互问题。

## 网课伴侣更新

- 视频控制会继续发送到实际持有媒体元素的子 frame。
- 聚焦只作用于外层课程页面：对于百家云直播回放，会铺满整个播放器 iframe，而不会把教师视频误放大覆盖 PPT 和目录。
- 保留百家云播放器内部的 PPT、目录和教师画面布局；Windows 原生浏览器小窗可继续操作其中的控件。
- 聚焦状态在课件翻页、计时器或聊天等频繁 DOM 变化期间保持稳定，避免画面反复跳变。

## 说明

- 正式发布包含更新后的 `QuizPane-course-companion.zip` 浏览器扩展包。
