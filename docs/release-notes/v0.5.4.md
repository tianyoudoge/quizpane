# 小窗刷题 v0.5.4

本次补丁修复 Windows 7 绿色版解压后程序文件名乱码，以及题库制作器看似缺失的问题。

## Windows 7 兼容修复

- Windows 7 包内的两个程序改用 `QuizPane.exe` 和 `QuizPaneStudio.exe`，避免系统自带 ZIP 解压器无法正确处理 UTF-8 中文文件名。
- 小窗刷题与题库制作器可同时识别新的 ASCII 文件名和旧中文文件名，保持已有安装及其他 Windows 包兼容。
- 自动更新可识别两种包结构；从旧版升级时会启动新包中的实际主程序。
- 打包流水线新增校验，确保 Windows 7 ZIP 内所有路径均为 ASCII，并继续验证两个程序的架构和 Qt 5 运行库完整性。

## 平台说明

- Windows 7 SP1 请下载独立的 x86 或 x64 兼容包。
- Windows 10/11 Qt 6 包与 macOS 包的程序名称和打包方式保持不变。
