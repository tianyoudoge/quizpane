# 小窗刷题 v0.6.0

本版本重点完善题库制作器的智能解析、复核体验与 Windows 7 兼容性，并修复大型合订 PDF 在低内存设备上的 OOM。

## 智能解析与题库整理

- 完善 MinerU 云解析后的分套、题号、选项、答案、材料及图片题整理规则。
- 支持无答案题库自动判定，无法可靠识别的内容进入人工复核，不猜测答案。
- 普通题的原卷校对图改为复核时按需生成，避免一次性持有数百张 PNG。
- 进度页逐题显示当前文件、分套、题目进度和已整理/待复核数量，不再长时间停在固定百分比。
- 删除实际会终止进程的“后台等待并关闭”入口。

## Windows 7 稳定性

- Win7 x64/x86 继续使用 Qt 5.15 与 MSVC v142，补齐 OpenSSL 1.1.1w、CRT、QtPdf 和离线 OCR 运行库验证。
- 整次规则生成及 Auto 重跑共享一个 PDF 渲染会话，避免 Qt5/PDFium 按分套重复打开 PDF 导致提交内存持续增长。
- PDF 渲染增加 Windows 内存压力保护：危险时跳过部分自动题图并继续文字整理，避免整项任务 OOM。
- 崩溃转储在详细 dump 写入失败时回退到轻量 minidump，避免只留下 0 字节文件。
- 诊断日志统一使用 UTF-8，并记录逐题进度、正式/复核附件和 Windows Private Usage。

## 性能与验证

- 降低 Win7 上翻题、目录加载与设置读写开销。
- 发布前 Release 全量自动化测试 29/29 通过。
- Win7 x64 测试包已通过编译、ZIP 依赖、PE 架构和离线 OCR 冒烟验证，并完成大型 147 页题本实机复测。
