# 小窗刷题 v0.4.0

这一版的重点，是让网课学习和刷题可以更自然地同时进行。

## 新增：网课伴侣浏览器扩展

- 新增 Chrome / Edge 网课伴侣扩展，可在课程网页中绑定学习页面。
- 课程视频可显示为独立的小窗，与刷题窗口配合使用，减少在浏览器和题目之间来回切换。
- 支持课程播放控制、学习进度联动和焦点切换，让刷题时仍能方便地管理课程。
- 老板键现可统一隐藏与恢复刷题窗口和课程视频小窗。

## macOS 体验改进

- 优化课程视频小窗的显示、置顶、隐藏和恢复流程，提升小窗在日常切换中的稳定性。
- 支持在需要时将源浏览器视频窗口停靠到屏幕边角，让独立视频小窗保持可用。
- 首次使用上述源窗口停靠能力时，macOS 会要求授予“小窗刷题”辅助功能权限；该权限仅用于控制本机浏览器窗口的位置和可见性。

## 刷题与题库制作体验

- 完善题库制作和资料整理流程，优化题目审阅、资料提取及生成相关体验。
- 改进跨平台窗口行为与构建交付稳定性，Windows、macOS 和 Linux 均可使用本次发布版本。

## 安装说明

桌面端请下载与系统匹配的安装包。若需要网课伴侣，请同时下载 `QuizPane-course-companion.zip`，解压后在 Chrome 或 Edge 的扩展管理页开启开发者模式并“加载已解压的扩展程序”。
