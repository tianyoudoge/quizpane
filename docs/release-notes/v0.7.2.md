# 小窗刷题 v0.7.2

本次小版本新增作答后的 AI 解析，并改善题目与解析中的数学公式显示。

## AI 解析

- 解析页支持生成 AI 解析，可选择供应商或配置兼容接口、模型与 API Key，并查看用量。
- 全局菜单、托盘菜单与 macOS 菜单提供“AI 解析设置…”入口，未打开题库也可提前配置。
- 请求包含材料、题干、选项和题库标准答案；图片题同时发送相关图片，缺失或损坏的图片会明确报错。
- 声明式题库自动保存生成的 AI 解析，切题或重新打开题库后可继续查看，也可主动重新生成。
- 优化深浅主题、加载动画和解析布局；支持清空已保存的 API Key。

## 公式与显示修复

- Windows 优先使用系统已安装的微软雅黑，改善题干、选项和解析字号、字重及段落间距，无需单独打包字体。
- 修复更改背景可见度或主题时中文字体回退的问题。
- 修复浅色主题中练习题干、解析文字及导航图标过淡的问题，已有图标随主题切换更新。
- 改善 Markdown 与 LaTeX 显示，支持分数、根号、上下标、括号和常用数学符号。
- 保留代码块中的字面内容，以及不支持的公式命令和参数。
- 修复练习页公式格式化器的构建链接问题。
- 修复背景可见度为 100% 时卡片仍透出底层窗口内容的问题。

AI 解析需要用户自行配置服务；生成内容与题库标准答案独立。原生插件题库的 AI 解析仅在当前会话保留。


## 验证范围

- Win7 x64 实机验证全局 AI 配置共享与保存、字体、深浅主题、三题作答交卷、Markdown 和公式。
- Win11 实机完成深色主题设置与作答解析冒烟验证；最新图标修复未单独做 Win11 实机复验。
- AI 界面回归使用缓存解析，未调用真实服务。
