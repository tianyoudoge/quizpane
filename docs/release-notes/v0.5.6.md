# 小窗刷题 v0.5.6

本次小版本完成题库制作器的 MinerU 云解析链路，用单一文档解析后端替代原有视觉 AI 辅助能力，同时保留本地解析与人工复核作为可靠兜底。

## MinerU 云解析

- 题目 PDF、扫描件及独立答案/解析册均可通过 MinerU 识别，并在同一规则引擎中完成题号、选项、答案和材料整理。
- 图片选项具备完整 A–D 版面坐标时，会生成四张独立选项图；坐标不完整时安全回退为原题截图并要求人工复核。
- 云解析默认关闭，只有用户明确允许后才上传资料；Token 存放在系统凭据存储中。
- Token 无法读取或云解析失败时自动退回本机 QtPdf/Tesseract 路径，不中断整批整理。

## 稳定性与交互

- 限流、服务端错误和短暂网络故障支持指数退避，并遵循服务端 `Retry-After`。
- 长任务自动降低轮询频率，减少不必要的接口请求。
- “取消整理”按钮和关闭窗口均可终止正在上传、轮询或下载的云任务。
- 移除旧视觉模型客户端、多厂商模型配置及相关遗留分块/检查点代码，设置页只保留 MinerU Token。

## 验证

- 新增 MinerU 协议状态机、版面适配、答案另册、图片选项和取消/重试回归测试。
- 本地全量构建成功，28 项自动化测试全部通过。
