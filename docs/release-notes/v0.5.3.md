# 小窗刷题 v0.5.3

本次补丁集中修复题库制作器的 PDF 识别、题号处理和复核页交互。

## 识别与答案配对

- 改善 PDF 题干划线与填空区域的保留，减少划线文字丢失、填空位置消失的问题。
- 支持一个题本包含多套独立编号的题目，保留分套信息和原始题号，不静默重编号。
- 支持提取题干括号中的明确选项答案，并将题干对应位置留空；疑似答案、选项不完整或答案冲突时保留原文并提示复核，避免误删正文。
- 取消仅因原题号重复或倒序而禁止生成、安装题库的限制。每道题仍有独立且唯一的内部 ID，保存答案、判分和练习记录不会因重号互相覆盖。
- 同号答案表无法唯一配对、同一题号存在冲突答案，或同页重号导致题图无法唯一定位时，仍要求人工核对，不猜测答案或共用错误截图。

## 复核页

- 将分类筛选改为可辨识选中状态的标签页，图片等复核类别使用明确的可点击样式。
- 补充批量复核与题库生成的提示，说明未采用的题目不会纳入题库。
- 为重号题显示“同号第几处”，窄列表保留标签首尾，便于区分和定位。

## 更新与兼容说明

- 请同时更新小窗刷题与题库制作器；旧版客户端可能仍按旧规则拒绝包含重号的题库。各平台完整安装包已同时包含两者。
- Windows 7 SP1 继续使用独立的 Qt 5.15 / MSVC v142 兼容包，提供 x86、x64 两种架构；Windows 10/11 使用 Qt 6 x64 包，macOS 提供 Intel 与 Apple Silicon 包。
- Windows 7 包仍不包含 OCR；扫描型 PDF 请先准备文字层或在较新系统中处理。
- 自动构建、测试与打包校验不替代目标系统实机验收，尤其建议在实际 Windows 7 设备上验证启动、PDF 导入和题库生成。
