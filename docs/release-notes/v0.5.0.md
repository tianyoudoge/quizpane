# 小窗刷题 v0.5.0

本次发布新增独立维护的 Windows 7 SP1 兼容构建，并完善对应的浏览器网课伴侣路径。

## Windows 7 SP1 兼容包

- 新增 `QuizPane-windows7-x64-portable.zip` 与
  `QuizPane-windows7-x86-portable.zip`，分别面向 64 位和 32 位 Windows 7 SP1。
- 使用 Qt 5.15 与 MSVC 2019/v142 构建，和 Windows 10/11 的 Qt 6 构建线相互独立。
- 绿色包内包含所需的 VC++ 与 UCRT 运行库，避免因缺少 `MSVCP140.dll` 等运行库而无法启动。
- PDF 导入功能可用；Windows 7 包不包含 OCR，扫描型 PDF 请先准备可提取的文字层，或在较新系统中处理。

## 网课伴侣

- Windows 的 Chrome / Edge 109+ 可使用原生浏览器 popup 路径打开视频小窗，并由桌面端进行置顶、隐藏和恢复。
- 保持 Chrome / Edge 116+ 上已有的行为不变；macOS 的实验捕获诊断仍要求 116+。

## 使用说明

- Windows 7 已停止安全支持，本版本提供的是独立兼容包；请先在目标设备完成启动、题库制作和视频小窗的冒烟验证，再用于日常环境。
- 其他平台的下载与使用方式保持不变。
