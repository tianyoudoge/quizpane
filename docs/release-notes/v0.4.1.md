# 小窗刷题 v0.4.1

本次为网课伴侣与官网的体验更新。

## 网课伴侣更新

- 扩展的版本检查和下载引导均改为使用小窗刷题官网，不再把用户直接带往 GitHub Release。
- 手动检查更新时会向官网请求一次受限刷新，确保能尽快看到最新版本。
- 同步更新扩展权限、隐私说明和商店上架文案，明确版本信息只通过官网获取。

## 官网使用引导

- 网课伴侣页面新增四步图文引导：添加扩展、固定图标、绑定课程视频，以及用老板键同步隐藏和恢复视频小窗与刷题小窗。
- 每个步骤卡片均可打开带箭头标注的截图说明，首次使用更容易上手。

## 说明

- `v0.4.0` 的发布说明继续保留，`v0.4.1` 仅记录本次增量更新。
