# 多套题本与划线识别回归

## 数据与行为

- 明确的“专项刷题一／二”“第 N 套试题”等标题界定套题。题号保持原样，来源增加可选的 `sectionId` / `sectionTitle`。
- 答案及解析、材料归属和漏题检查按套隔离。原题号仅用于对照，可重复或倒序；题目 ID 必须唯一。
- 同套重号题可同时采用；题内答案直接绑定本题，无法仅按题号区分的答案表/解析不自动配对，留待人工确认。
- 仅在反复出现在页边缘时去除页眉页脚；分套标题不进入上一题选项。
- 数字开头题干支持 `17.2012年…` 和 `7.20世纪…`，保留普通小数防误判。
- “材料接下来…”和“说明波的性质…”属于普通正文，不作为材料或解析标题。
- 下划线使用白底渲染、文字基线附近的完整水平线段、文字坐标交叉检测。文字下划线保存为 `stemUnderlines`；空白横线保存为 `〔填空〕`，包括文字层丢失的句首空白。
- 制作器与刷题端均展示题干下划线。手工编辑题干会要求重新确认偏移；支持手动添加和清除下划线。填空采用 Qt5/Qt6 均支持的下划线空格，不能依赖浏览器专用 CSS。
- 未确认的版式进入软复核；没有恢复出标记时附原文截图。重复选项可能表示漏印题号或跨题拼接，保留完整内容和截图并进入硬复核，不静默去重或猜题号。

新增字段需要配套的新版制作器和刷题端；旧题库不需要迁移。不要用旧版校验器检验含新字段的题库。

## 自动检查

现有测试覆盖分套答案隔离、真实页码、重号题独立保存/判分/打包、歧义答案表保护、正文边界、透明背景、单字下划线与空白线区分、句首填空、下划线范围校验以及 Provider 的 HTML 输出。

```sh
cmake --build build/release-macos --parallel 4
ctest --test-dir build/release-macos --output-on-failure
```

147 页的《2026 国考专项刷题课题本》不提交仓库。提供本地路径后可运行真实样本断言；内容不会上传到云端：

```sh
QUIZPANE_VERIFY_BOOKLET=1 build/release-macos/tests/pdf_regression_harness \
  "$BOOKLET_PDF" build/booklet-regression
```

预期：20 套、598 道结构可用题、1 个硬复核题块、0 个误识别共享材料。第 61 页原卷没有印第 11 题的题号，其内容连同第 10 题保留在硬复核题块，必须人工拆分确认。结构可用题中的版式软复核仍需确认后才能进入最终包。

样本断言核对第 67 页四处准确划线、第 99 页前四题的 1/2/1/3 个填空及第 81 页句首填空，并检查选项无页眉页脚或套题标题污染。`review-report.json` 保存待复核内容与漏题提示。

发布前还需通过 Windows 7 工作流的 Qt 5.15 / MSVC v142 x64、x86 构建、测试和 ZIP 校验；Mac 的 Qt6 测试不能替代 Windows 实机验证。
