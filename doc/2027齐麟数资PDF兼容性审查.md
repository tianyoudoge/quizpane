## 范围

仅审查以下四种标准版式，其余速算、连连看、刷题计划、读题圈圈等资料不纳入兼容范围：

- `刷题组02——资料分析套题（上）（2027）.pdf`
- `刷题组03——资料分析套题（下）（2027）.pdf`
- `刷题组06——数量关系套题（2027）.pdf`
- `刷题组07——一天一题学数量&葫芦兄弟&资料分析高频错题精选（2027）.pdf`

所有样本均有可用 PDF 文字层，不需要 OCR。审查使用与 GUI 相同的 `PdfExtractor` 和
`RuleBasedBankGenerator`，CLI 只是开发者内测入口，不另建识别算法。

### 修复原则

1. GUI 和 CLI 继续共用唯一生产识别入口；CLI 只负责回测和输出，不加入独立清洗逻辑。
2. 页眉、页脚和 07 的笔记框必须依据稳定版面证据过滤，不用宽泛文本关键词删除题干。
3. 题块终点优先使用下一题、下一材料或下一套卷的明确边界，防止跨材料和跨套卷粘连。
4. 02/03/06 的答案以规范化套卷名建立 `(suiteId, questionNumber)` 身份；只在套卷名唯一对齐、
   答案数和该套题数一致时自动绑定。
5. 套卷答案无法唯一对齐时必须整套转待复核，不回退到文档级“题号 → 答案”猜测。
6. 修复后用同一固定种子重放这 10 题，目标是保持语义 `10/10`、将严格结构提升到 `10/10`，
   并单独验证套卷级答案匹配，同时跑完全部既有回归。

## 已落地

1. `PdfExtractor::extract(path)` 默认全卷行为保持不变；新增显式的原文页码范围和两侧外扩，
   避免影响既有 GUI 与大规模回归。
2. 范围提取保留原 PDF 页码，生成结果不会把原第 80 页误报为第 1 页。
3. 开发者 CLI 只调用 GUI 同一个生产识别入口，支持显式页区间、外扩和 GUI 已有的
   无答案模式；CLI 不维护任何识别或自动过滤算法。
4. 07 的 `001-题干`、`葫芦兄弟 029` 下的【原型】/【改编】、`资料分析高频错题精选
   124` 已做受限归一化；现代年份 1900-2099 不再作为题号锚点。
5. CLI 目标为 `EXCLUDE_FROM_ALL`，不进入默认构建和发行包。
6. 四本目标讲义的固定页眉页脚、二维码提示和“听视频记笔记”已进入共用生产引擎的
   受限边界规则；同样文字出现在非目标 PDF 时保持旧行为。
7. `X、根据以下资料` 已作为下一材料硬边界，避免最后一个选项吞入下一资料。
8. 02/03/06 已按套卷键匹配答案；标题重复、题号不连续、缺题或答案数量不一致时整套复核。
9. 07“一天一题”已支持答案范围与字符数严格等长的安全子集；复杂练习、葫芦兄弟和
   资料高频错题答案仍保守复核。

## 后续优先级

### P0：套卷级答案身份

02/03/06 在一本 PDF 中包含多套试卷，每套都从第 1 题重新编号，答案集中在末尾并以
`2015 国考`、`2021 联考 A` 等套卷名分组。现有生成器使用文档级 `题号 -> 答案` 映射，
无法区分多个“第 1 题”。完整 02 含答案运行仅 1 题直接通过、784 题待复核，说明不能把
当前答案结果用于生产。

正确改法是先识别套卷 section，为题目建立 `(sectionId, questionNumber)` 身份，再把末尾
`【参考答案】CCDBA ...` 按 section 和题目顺序展开。无法一一对应时必须待复核，不能回退到
全局题号猜测。

### P1：07 的语义分组

07 的葫芦兄弟包含“原型 + 一个或多个改编”，错题精选有时一页两题；当前已能建立题目锚点，
但讲解中的 `1.`、`2.` 步骤仍可能成为伪题。建议给这两类标题建立明确的 section 终点，且只在
标题到下一个同类标题之间接受【原型】/【改编】锚点。

### P1：范围完整性诊断

外扩可以降低截断概率，但不能证明边界完整。后续若增加边界诊断，也必须落在 GUI/CLI 共用的
生产引擎中：首尾页是否以选项续行开始、末题是否缺选项、材料是否从上一页开始、下一页是否仍
属于同一题。CLI 不得自行静默删除中间无题号的资料页。

### P2：非题目页分类

目录、刷题须知、二维码说明、歌词/寄语等前后页可按页面级证据排除；资料图表页即使没有题号
也必须保留。推荐输出 `question / material / answer / front-matter / trailing-matter / unknown`
六类及证据，而不是简单布尔删除。
