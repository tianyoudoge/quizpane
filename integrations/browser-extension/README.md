# 小窗刷题网课伴侣（开发版）

这是 QuizPane 的 Chromium 扩展，连接固定的本机地址：

```text
ws://127.0.0.1:49752/quizpane-browser/v1
```

它不需要配对码，不读取 Cookie、课程正文或视频地址。当前版本只在用户点击“绑定当前课程”后请求该站点权限，并控制顶层页面的标准 HTML5 `<video>`；绑定后会把网页标题、播放状态和当前/总时长同步到本机 QuizPane。

## 开发安装

1. 先启动已启用 Qt WebSockets 的 QuizPane。
2. 打开 Chrome 或 Edge 的扩展管理页并开启开发者模式。
3. 选择“加载已解压的扩展程序”，目录选择本文件夹。
4. 打开课程播放页，点击扩展图标，选择“绑定并进入视频聚焦小窗”。

扩展会把当前标签页移到独立浏览器小窗，隐藏播放器以外的网页元素，并记住原浏览器窗口和标签位置。第一次按 QuizPane 老板键会暂停已播放的视频并最小化课程小窗；第二次会恢复小窗并尝试恢复播放。可在扩展弹窗或 QuizPane 托盘的“网课视频”菜单中选择“放回原浏览器”。

标准 HTML5 `<video>` 会保留所在播放器容器的自定义控制条；若课程播放器位于跨域 iframe，聚焦模式会优先只展示该 iframe。跨域 iframe 的暂停/恢复控制仍需要相应站点权限和后续适配。

浏览器的自动播放策略可能拒绝恢复，这时可在扩展弹窗点击“暂停 / 继续”。

## 新版提醒

扩展会在启动后、每 6 小时以及用户点击弹窗中的“检查扩展更新”时，读取官网
的版本接口。只有当最新版同时包含 `QuizPane-course-companion.zip` 且版本
号高于本地版本时，弹窗才会显示更新提醒。该提醒不会自动下载或修改扩展文件；更新
仍需下载新版 ZIP、覆盖此前已加载的目录，然后在扩展管理页点击“刷新”。
