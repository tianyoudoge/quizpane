# Chrome Web Store 上架清单

## 可直接填写的文案

**名称**：小窗刷题网课伴侣

**简短说明**：让 QuizPane 老板键暂停、恢复并收起当前网页课程视频。

**详细说明**：

小窗刷题网课伴侣与本机小窗刷题桌面端连接。用户在课程播放页主动绑定后，可将当前标签页移动到独立课程小窗；小窗刷题老板键会暂停视频并最小化课程小窗，再次按下会恢复窗口并按原播放意图继续播放。

扩展只支持标准 HTML5 视频，不下载、不提取视频地址、不绕过 DRM、不修改学习进度，也不提供自动刷课功能。

**权限说明**：

- `storage`：在本机保存绑定标签页、课程小窗状态与最近一次版本检查结果。
- `tabs`：定位用户主动绑定的当前标签页，并在原窗口与课程小窗之间移动该标签页。
- `scripting` 与按需站点权限：仅在用户点击绑定后检测和控制当前课程页的 HTML5 视频。
- `http://127.0.0.1/*`：连接同一台电脑上 QuizPane 的本机桥接服务；不连接局域网或公网服务。
- `https://xutianyou.cc/*` 与 `alarms`：每 6 小时读取官网版本号，用于显示新版提醒；不上传课程数据或用户数据。

## 发布前仍需人工完成

1. 注册 Chrome Web Store Developer 账号并开启两步验证。
2. 将 `PRIVACY.md` 发布为可公开访问的隐私政策网页，并在商店 Privacy practices 中填写该 URL。
3. 准备至少一张实际产品截图（建议：绑定前、课程小窗、老板键恢复后各一张）。
4. 运行 `scripts/package-extension.sh`，上传生成的 ZIP，填写 Store listing 和 Privacy practices，先以“不公开”发布给测试者。

不要在商店填写“不会处理用户数据”：扩展在本机处理页面标题和视频状态，必须如实披露，即使数据不会离开用户设备。
